# AWS and Linux Labs

This directory contains guided, hands-on lab notes covering foundational cloud engineering and systems operations topics. Use the subject indexes below to navigate the material.

> These are learning exercises performed in lab environments. Follow each lab's own instructions and verify the state of resources in your environment.

## Browse by subject

### [Linux Fundamentals](Linux%20Fundamentals/README.md)
Bash and shell usage, filesystems, users and groups, processes, services, logs, software management, editors, SSH, and backup operations.

### [Compute Services](Compute%20Services/README.md)
Amazon EC2, S3, EBS, Lambda, Linux server setup, storage management, and static website hosting exercises.

### [Networking](Networking/README.md)
VPCs, subnets, IP addressing, networking resources, web-server connectivity, and troubleshooting commands.

### [Databases](Databases/README.md)
Database table operations, querying and modifying data, Amazon Aurora, DynamoDB, and database-backed application exercises.

### [Management and Governance](Management%20and%20Governance/README.md)
CloudTrail and CloudFormation troubleshooting exercises.

## Suggested learning path

1. Build Linux command-line confidence.
2. Learn IP addressing, subnets, and basic network troubleshooting.
3. Practice provisioning and operating AWS compute and storage resources.
4. Explore databases and application connectivity.
5. Study governance, audit trails, and infrastructure troubleshooting.
