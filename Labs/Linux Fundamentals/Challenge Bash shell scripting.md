## The challenge task

I wrote a Bash script that met these requirements:

- It created 25 empty (0 KB) files using the `touch` command.
- File names followed the pattern `<yourName><number>`, e.g., `alex1`, `alex2`, ...
- Each time the script ran it created the next batch of 25 files, continuing numbering from the maximum number already present in the target folder.
- The numbering was not hard-coded — it was generated by the script logic.

I placed, executed, and tested the script in the current working directory for the lab exercise.

## Approach and implementation notes

I followed these steps to implement the solution (described in past tense):

1. I chose a name prefix (for example `alex`).
2. I scanned the directory for existing files matching the prefix and numeric suffix (using a shell pattern and numeric extraction via parameter expansion or a regular expression).
3. I computed the maximum existing index; if no matching files existed I set the start index to 1.
4. I created a loop that iterated 25 times and called `touch` to create files with incrementing numbers starting at (max_index + 1).
5. I made the script executable with `chmod +x` and I ran it.

The solution was robust to missing files and to gaps in numbering: it always started at the highest existing number + 1.

## Example script (one valid implementation)

Below was an example implementation I used and tested. It was included here so others could reproduce or adapt it.

```bash
#!/usr/bin/env bash
# create_25.sh — create 25 empty files with prefix and sequential numbers

PREFIX="alex"        # replace 'alex' with your chosen name/prefix
COUNT=25

auto_max() {
  # Find files matching prefix followed by a number, extract numeric suffix, print max
  shopt -s nullglob
  max=0
  for f in "${PREFIX}"*[!~]; do
    # Extract numeric suffix: remove prefix, non-digits ignored
    num=${f#${PREFIX}}
    # Only consider purely numeric suffixes
    if [[ "$num" =~ ^[0-9]+$ ]]; then
      (( num > max )) && max=$num
    fi
  done
  echo "$max"
}

max_index=$(auto_max)
start=$((max_index + 1))
end=$((start + COUNT - 1))

for i in $(seq "$start" "$end"); do
  touch "${PREFIX}${i}"
done

echo "Created ${COUNT} files: ${PREFIX}${start} .. ${PREFIX}${end}"
```

Notes about the example above:
- I replaced `alex` with my own prefix when I ran it; other users were instructed to change PREFIX accordingly.
- The helper function handled cases with no existing files by returning 0.
- The script used only POSIX-friendly constructs (with Bash-specific shopt and regex checks) and it created files with `touch` so they were 0 bytes.

## Hints (if you had been stuck)

- I used `ls ${PREFIX}[0-9]*` or `printf "%s\n" ${PREFIX}[0-9]*` to list candidate files; globbing and nullglob/shopt helped avoid literal patterns when no matches existed.
- I used parameter expansion `${f#${PREFIX}}` to remove the prefix and obtain suffix text.
- I used a numeric test `[[ "$num" =~ ^[0-9]+$ ]]` to ensure I only considered files with numeric suffixes.
- `seq` or a `for ((i=...))` loop were both suitable to generate the 25 numbers.
